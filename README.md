A single original office joke, exactly one line of 102 characters, written for the make.fun 24-hour sprint. It pokes fun at the daily standup that drags on forever because no one dares to be the first to end it with the classic escape line.

> "The standup ran 45 minutes because nobody wanted to be the one to say 'let's take this offline' first."

Run it with `node main.ts`. Prize pool $2; deadline 25 Nov 2026.
